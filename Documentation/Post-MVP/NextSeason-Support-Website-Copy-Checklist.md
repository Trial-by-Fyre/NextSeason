# NextSeason Support Website Copy Checklist

Living checklist for `getnextseason.com` support pages, FAQ entries, and
support-email templates. Historical transcripts and planning documents stay
unchanged; update this file when support-facing copy changes.

## Product scope (FAQ / support)

- [ ] **Season and premiere information:** NextSeason reports original and
  new-season premiere information from its TV data sources. It helps users
  follow when the next season is announced, scheduled, or airing.
- [ ] **Streaming availability:** NextSeason does **not** currently track
  country-specific streaming availability (where to watch). Do not promise
  provider or regional “where to stream” answers in support copy until a
  dedicated data source is integrated.

## Verification

- [ ] FAQ and support pages match the bullets above before each public website
  update.
- [ ] App Store description and in-app About/Support links remain consistent
  with the website (see
  [App Store Readiness Roadmap](NextSeason%20-%20App%20Store%20Readiness%20Roadmap.md)).
