# Working with AI

Standing instructions for AI tools working in this repository:

- Keep changes tightly scoped to the requested task.
- Do not modify files merely because their contents became outdated as a consequence of the current task.
- Do not modify transcripts, conversation history, or historical/archive files. They record what happened and must remain unchanged.
- Do not modify roadmaps, planning documents, or other project documentation unless the task explicitly requests documentation changes.
- Do not reformat existing files unless formatting is explicitly part of the task.
- Do not perform unrelated cleanup, refactoring, renaming, modernization, or style changes while implementing another task.
- Preserve the project's existing structure, conventions, and formatting unless there is a specific reason to change them.
- Do not treat placeholder, mock, test, or historical values as authoritative configuration. If a real value is required and has not been provided, stop and ask.
- Display StoreKit product prices using StoreKit's localized pricing, not hard-coded price strings.
- Report advisable changes outside the requested scope instead of making them.
- After completing a task, report exactly which files changed and briefly explain why each changed.
- If the requested change cannot be completed safely without missing information, stop and ask rather than guessing.
